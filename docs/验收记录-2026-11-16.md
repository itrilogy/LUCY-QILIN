## 2. 产品链路验收

端到端用例：`tests/test_acceptance.py`。不依赖真实技能仓库，也不在商店服务器上执行安装。

### 技能包

1. 构造一个合法技能目录（`manifest.json` + `SKILL.md`）。
2. `submit_directory` 走 `begin_submit` → PUT → `finish_submit`，进入 `pending`。
3. 管理员通过 HTTP `approve` 发布。
4. `/v1/catalog` 能搜到；`/v1/packages/<id>/<version>` 返回公开清单。
5. `POST /v1/install-plan` 生成 `download → unpack → verify`。
6. `store-install --dry-run` 返回 0，不实际下载。

### 知识包

1. 用 `store/spec/knowledge-example.json` 落盘为最小合格包。
2. 同样走上传 → `pending` → 发布。
3. `/v1/catalog?kind=knowledge` 能搜到；`describe` 返回 `knowledge.taxonomy`。
4. 安装计划为 `download → unpack → verify`，干跑通过。
